\# Carbon Footprint Tracker



A web-based application designed to help users track their daily habits and understand their environmental impact. The application encourages eco-friendly practices through habit tracking.



\## Features



\- Add and track daily habits

\- Record eco-friendly activities

\- Manage habit records

\- Web-based user interface



\## Technologies Used



\- Java

\- Spring Boot

\- Spring MVC

\- Thymeleaf

\- HTML

\- CSS

\- JavaScript

\- Maven



\## How to Run



1\. Clone the repository.

2\. Open the project folder.
